\noindent \textbf{Description} \\ 
\textbf{Actors:} Student, Tutor, Admin, System, HCMUT\_SSO, HCMUT\_DATACORE, HCMUT\_LIBRARY, Database

\begin{enumerate}
    \item Student, Tutor, and Admin access the system
    \item System sends SSO login request to HCMUT\_SSO
    \item HCMUT\_SSO returns authentication token with user role
    \item System stores authentication session in Database
    \item System requests user data synchronization from HCMUT\_DATACORE
    \item HCMUT\_DATACORE returns user profiles and academic data
    \item System updates user profiles in Database
    \item Database confirms synchronization completion
    \item System requests resource access from HCMUT\_LIBRARY
    \item HCMUT\_LIBRARY returns learning resources and metadata
    \item System stores resource references in Database
    \item Database confirms resources updated
    \item System sends profile and resource updates to Student
    \item System sends profile and resource updates to Tutor
    \item System sends profile and resource updates to Admin
\end{enumerate}
