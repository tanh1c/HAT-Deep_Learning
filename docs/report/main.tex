\subsection{Image Track --- CIFAR-10, ResNet-18, and ViT-B/16}

\subsubsection{Problem and Dataset Exploration}
The image task is a multi-class image classification problem on the \textbf{CIFAR-10} dataset. The goal is not only to train a classifier, but also to compare two major pretrained model families under the same evaluation protocol:
\begin{itemize}[leftmargin=*, nosep]
    \item \textbf{ResNet-18} as the CNN baseline,
    \item \textbf{ViT-B/16} as the Transformer-based vision model.
\end{itemize}

CIFAR-10 is a suitable dataset for this assignment because it has \textbf{10 classes}, satisfies the requirement of at least 5 classes, is significantly more meaningful than very simple benchmarks such as MNIST, and is challenging enough to expose differences between CNN and ViT transfer learning.

Basic dataset statistics:
\begin{itemize}[leftmargin=*, nosep]
    \item training split: \textbf{50,000} images,
    \item test split: \textbf{10,000} images,
    \item balanced test set: \textbf{1,000} images per class,
    \item original image size: \textbf{$32 \times 32$}.
\end{itemize}

The 10 classes are: \textit{airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck}. From the confusion matrices and classification reports in the notebooks, the remaining errors are concentrated mainly in visually similar categories rather than clearly distinct classes. This makes CIFAR-10 a useful benchmark for comparing representation quality, calibration behavior, and qualitative interpretability between CNN and ViT architectures.

Beyond satisfying the assignment requirement, CIFAR-10 is also a good fit for this project because it is:
\begin{itemize}[leftmargin=*, nosep]
    \item large enough to demonstrate transfer learning behavior,
    \item balanced enough to make cross-model comparison straightforward,
    \item and suitable for follow-up extensions such as interpretability and calibration analysis.
\end{itemize}

\subsubsection{Dataset, DataLoader, and Augmentation Setup}
Both notebooks load CIFAR-10 from \texttt{torchvision.datasets.CIFAR10}. Because both backbones are pretrained on ImageNet, the original $32 \times 32$ images are resized to \textbf{$224 \times 224$} before entering the networks.

Common preprocessing choices:
\begin{itemize}[leftmargin=*, nosep]
    \item \texttt{Resize((224, 224))},
    \item conversion to tensor,
    \item normalization using CIFAR-10 statistics.
\end{itemize}

Normalization values used in both notebooks:
\[
\texttt{mean} = (0.4914, 0.4822, 0.4465), \qquad
\texttt{std} = (0.2470, 0.2435, 0.2616)
\]

Common DataLoader configuration:
\begin{itemize}[leftmargin=*, nosep]
    \item \texttt{batch\_size = 64},
    \item \texttt{shuffle = True} for training and \texttt{False} for testing,
    \item \texttt{num\_workers = 4},
    \item \texttt{pin\_memory = True},
    \item \texttt{persistent\_workers = True}.
\end{itemize}

The augmentation policy is better described as \textbf{moderate} rather than minimal.

For \textbf{ResNet-18}, the training transform includes:
\begin{itemize}[leftmargin=*, nosep]
    \item horizontal flip,
    \item random rotation,
    \item color jitter,
    \item random affine translation,
    \item random erasing.
\end{itemize}

For \textbf{ViT-B/16}, the training transform includes:
\begin{itemize}[leftmargin=*, nosep]
    \item horizontal flip,
    \item random rotation,
    \item color jitter,
    \item random erasing.
\end{itemize}

For evaluation, both notebooks use the same simpler test transform:
\begin{itemize}[leftmargin=*, nosep]
    \item \texttt{Resize((224, 224))},
    \item \texttt{ToTensor()},
    \item \texttt{Normalize(mean, std)}.
\end{itemize}

The resize step is necessary for reuse of ImageNet-pretrained feature extractors. Although upsampling CIFAR-10 images does not create new visual information, it still works well in practice for transfer learning and produces strong performance on both backbones.

\subsubsection{Model Building, Training, Evaluation, and Comparison}
The \textbf{ResNet-18} baseline is initialized with ImageNet-pretrained weights and the final classification head is replaced for 10 CIFAR-10 classes. The CNN notebook uses full fine-tuning with the following main setup:
\begin{itemize}[leftmargin=*, nosep]
    \item epochs: \textbf{30},
    \item learning rate: \textbf{$3 \times 10^{-4}$},
    \item weight decay: \textbf{$10^{-4}$},
    \item warmup epochs: \textbf{3},
    \item optimizer: \textbf{AdamW},
    \item scheduler: \textbf{Linear warmup + CosineAnnealingLR}.
\end{itemize}

The model has \textbf{11.18M} parameters and reached a final reported test accuracy of \textbf{96.55\%}.
In the notebook logs, the first validation-style accuracy already reached about \textbf{75.5\%}, and the training time per epoch was roughly \textbf{55--80 seconds}, which makes ResNet-18 a strong and efficient baseline.

The \textbf{ViT-B/16} model is also initialized with ImageNet-pretrained weights and uses a two-phase fine-tuning strategy:
\begin{itemize}[leftmargin=*, nosep]
    \item \textbf{Phase 1}: freeze the backbone and train only the classifier head for \textbf{3 epochs} with learning rate \textbf{$10^{-3}$},
    \item \textbf{Phase 2}: unfreeze and fine-tune the full network for \textbf{15 epochs} with learning rate \textbf{$3 \times 10^{-5}$},
    \item optimizer: \textbf{AdamW},
    \item scheduler: \textbf{CosineAnnealingLR},
    \item weight decay: \textbf{$10^{-4}$}.
\end{itemize}

The Transformer model has \textbf{85.81M} parameters and reached a final reported test accuracy of \textbf{98.36\%}.
The first training phase already reached about \textbf{95.32\%}, and the notebook logs show epoch times of roughly \textbf{69--90 seconds}. This confirms that ViT-B/16 quickly benefits from transfer learning and then improves further during full-network fine-tuning.

For fair comparison, both models are evaluated on the same CIFAR-10 test set with:
\begin{itemize}[leftmargin=*, nosep]
    \item \textbf{accuracy},
    \item \textbf{classification report},
    \item \textbf{confusion matrix},
    \item and, for the extension part, \textbf{Expected Calibration Error (ECE)} plus reliability diagrams.
\end{itemize}

\hline

\subsubsection{Experimental Results, Figures, Analysis, and Discussion}
The final results show that both models are strong, but \textbf{ViT-B/16} is the better overall performer:
\begin{itemize}[leftmargin=*, nosep]
    \item ResNet-18 test accuracy: \textbf{96.55\%},
    \item ViT-B/16 test accuracy: \textbf{98.36\%},
    \item ResNet-18 ECE: \textbf{0.020006},
    \item ViT-B/16 ECE: \textbf{0.006917}.
\end{itemize}

This indicates that ViT-B/16 is not only more accurate, but also better calibrated. In other words, its confidence estimates are more trustworthy on average.

Additional notebook outputs already available for analysis include:
\begin{itemize}[leftmargin=*, nosep]
    \item confusion matrix for ResNet-18,
    \item confusion matrix for ViT-B/16,
    \item classification reports for both models,
    \item training curves,
    \item exported calibration metrics.
\end{itemize}

From the experimental comparison, several conclusions can be drawn:
\begin{itemize}[leftmargin=*, nosep]
    \item \textbf{Accuracy}: ViT-B/16 consistently achieves the strongest final performance.
    \item \textbf{Efficiency}: ResNet-18 remains much smaller (\textbf{11.18M} vs \textbf{85.81M} parameters) and therefore provides a better accuracy-efficiency trade-off.
    \item \textbf{Error pattern}: the hardest cases are concentrated in visually similar categories, especially at low image resolution.
    \item \textbf{Calibration}: ViT-B/16 has significantly lower ECE, so its confidence is better aligned with actual correctness.
\end{itemize}

Therefore, the experiment supports a clear interpretation: \textbf{ResNet-18} is a strong and efficient CNN baseline, while \textbf{ViT-B/16} is the strongest model in both predictive quality and reliability.

\subsection{Multimodal Track --- UPMC-Food101 Subset, CLIP ViT-B/16, and CLIP RN50}

\subsubsection{Problem and Dataset Exploration}
The multimodal task uses paired image-text inputs and compares \textbf{zero-shot} and \textbf{few-shot} multimodal classification. The report uses a 10-class subset of UPMC-Food101 and treats CLIP ViT-B/16 as the main backbone, with CLIP RN50 as the extension backbone. The task is well aligned with the assignment because each sample contains a true image-text pair rather than an artificially matched pair.

\subsubsection{Dataset, DataLoader, and Augmentation Setup}
The report page documents train/validation/test statistics and class-wise few-shot sampling. The custom multimodal dataset returns \texttt{(image, text, label)} tuples, supports augmentation and no-augmentation settings, and keeps the image and text branches aligned through the same label space. The 10 selected classes are: \textit{donuts, french\_fries, hamburger, hot\_dog, ice\_cream, pho, pizza, steak, sushi, tacos}.

\subsubsection{Model Building and Method}
The core backbone is CLIP, which provides both an image encoder and a text encoder in a shared embedding space. The multimodal report compares:
\begin{itemize}[leftmargin=*, nosep]
    \item zero-shot classification with prompt matching,
    \item few-shot adaptation with a \textbf{Linear classifier},
    \item few-shot adaptation with a \textbf{Prototype-based classifier},
    \item augmentation vs no-augmentation across ViT-B/16 and RN50.
\end{itemize}
