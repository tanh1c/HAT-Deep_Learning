\section{Detailed Dataset Reports}

\subsection{Image Track --- CIFAR-10, ResNet-18, and ViT-B/16}

\subsubsection{Problem and Dataset Exploration}
The image task studies supervised classification on the CIFAR-10 dataset and compares two model families:
\begin{itemize}[leftmargin=*, nosep]
    \item a CNN baseline based on \textbf{ResNet-18},
    \item a Transformer-based vision model based on \textbf{ViT-B/16}.
\end{itemize}
The dataset contains 10 balanced classes (\textit{airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck}). It is suitable for the assignment because it is standardized, well understood, and strong enough to reveal performance differences between CNN and ViT transfer learning.

\subsubsection{Dataset, DataLoader, and Augmentation Setup}
Both image notebooks use the same CIFAR-10 source for a fair comparison. Since both backbones are pretrained on ImageNet, the original $32 \times 32$ images are resized to $224 \times 224$ before training and inference. The common preprocessing pipeline includes tensor conversion and normalization. Augmentation is moderate rather than minimal:
\begin{itemize}[leftmargin=*, nosep]
    \item \textbf{ResNet-18:} horizontal flip, random rotation, color jitter, random affine translation, and random erasing.
    \item \textbf{ViT-B/16:} horizontal flip, random rotation, color jitter, and random erasing.
\end{itemize}

\subsubsection{Model Building, Training, Evaluation, and Comparison}
The CNN baseline uses ImageNet-pretrained ResNet-18 with the classification head replaced for 10 CIFAR-10 classes. The Transformer model uses ImageNet-pretrained ViT-B/16 and a two-phase training schedule: freeze the backbone for 3 epochs and then fine-tune all layers for 15 epochs. Both models are evaluated on the same CIFAR-10 test set using accuracy, macro F1, confusion matrices, classification reports, and calibration metrics.

\begin{center}
\small
\begin{tabular}{|l|l|c|c|c|}
\hline
\textbf{Model} & \textbf{Family} & \textbf{Params} & \textbf{Test Accuracy} & \textbf{ECE} \\
\hline
ResNet-18 & CNN & 11.18M & 96.55\% & 0.020006 \\
\hline
ViT-B/16 & Transformer & 85.81M & 98.36\% & 0.006917 \\
\hline
\end{tabular}
\end{center}

\subsubsection{Experimental Results, Figures, Analysis, and Discussion}
The ViT model achieves the strongest final accuracy and the best calibration, while ResNet-18 remains much smaller and cheaper to fine-tune. This means ViT-B/16 is the better absolute performer, but ResNet-18 offers a stronger accuracy-efficiency trade-off for lighter deployment scenarios. The remaining classification errors are concentrated in visually similar classes rather than clearly distinct categories, which is expected on CIFAR-10.

\subsubsection{Problem and Dataset Exploration}
The text task compares recurrent and Transformer-based text classification models on the \textbf{20 Newsgroups} dataset. The report page studies topic classification across 20 classes and highlights both semantic overlap and vocabulary differences between categories. The dataset contains 18,846 documents and is suitable for comparing sequence-based and self-attention-based architectures.

\subsubsection{Model Building, Training, Evaluation, and Comparison}
The BiLSTM-with-attention model provides the recurrent baseline. Transformer-based experiments use pretrained language models and evaluate multiple fine-tuning strategies, including freeze-backbone, hybrid fine-tuning, and full fine-tuning. \subsection{Multimodal Track --- UPMC-Food101 Subset, CLIP ViT-B/16, and CLIP RN50}

\subsubsection{Problem and Dataset Exploration}
The multimodal task uses paired image-text inputs and compares \textbf{zero-shot} and \textbf{few-shot} multimodal classification. The report uses a 10-class subset of UPMC-Food101 and treats CLIP ViT-B/16 as the main backbone, with CLIP RN50 as the extension backbone. The task is well aligned with the assignment because each sample contains a true image-text pair rather than an artificially matched pair.

\subsubsection{Dataset, DataLoader, and Augmentation Setup}
The report page documents train/validation/test statistics and class-wise few-shot sampling. The custom multimodal dataset returns \texttt{(image, text, label)} tuples, supports augmentation and no-augmentation settings, and keeps the image and text branches aligned through the same label space. The 10 selected classes are: \textit{donuts, french\_fries, hamburger, hot\_dog, ice\_cream, pho, pizza, steak, sushi, tacos}.

\subsubsection{Model Building and Method}
The core backbone is CLIP, which provides both an image encoder and a text encoder in a shared embedding space. The multimodal report compares:
\begin{itemize}[leftmargin=*, nosep]
    \item zero-shot classification with prompt matching,
    \item few-shot adaptation with a \textbf{Linear classifier},
    \item few-shot adaptation with a \textbf{Prototype-based classifier},
    \item augmentation vs no-augmentation across ViT-B/16 and RN50.
\end{itemize}

\begin{figure}[H]

\subsubsection{Experimental Results, Figures, Analysis, and Discussion}
The main ViT-B/16 backbone already achieves a strong zero-shot result and improves further with few-shot adaptation. The Prototype head is the most stable setting overall. RN50 is still competitive, but it is less consistent than ViT-B/16 and reacts more strongly to the chosen head and augmentation setting.
