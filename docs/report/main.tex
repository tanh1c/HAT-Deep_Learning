\subsection{Image Track --- Stanford Dogs, ResNet-18, and ViT-B/16}

\subsubsection{Problem and Dataset Exploration}
The final image track uses the \textbf{Stanford Dogs} dataset instead of the earlier CIFAR-10 setup. This benchmark is more suitable for the assignment because it is a \textbf{fine-grained image classification} task with \textbf{120 dog-breed classes}, \textbf{12,000 official training images}, and \textbf{8,580 official test images}. The dataset therefore satisfies the assignment size requirement comfortably while also making the CNN-versus-Transformer comparison more meaningful.

The image task compares:
\begin{itemize}[leftmargin=*, nosep]
    \item \textbf{ResNet-18} as the CNN baseline,
    \item \textbf{ViT-B/16} as the Transformer-based vision model.
\end{itemize}

Exported EDA results show that Stanford Dogs contains broad variation in brightness, saturation, image size, aspect ratio, and real-world scene composition. The class distribution is only moderately imbalanced, with a minimum of \textbf{148} and a maximum of \textbf{252} images per breed. This makes the dataset suitable for evaluating both representation quality and error patterns on visually similar classes.

\subsubsection{Dataset, DataLoader, and Augmentation Setup}
The final workflow preserves the official Stanford Dogs train/test split and creates an internal stratified validation split from the official training set only:
\begin{itemize}[leftmargin=*, nosep]
    \item train: \textbf{10,200} images,
    \item validation: \textbf{1,800} images,
    \item test: \textbf{8,580} images.
\end{itemize}

Because both backbones are initialized from ImageNet-pretrained weights, the preprocessing pipeline resizes images to \textbf{256}, crops them to \textbf{224}, converts them to tensors, and normalizes them using \textbf{ImageNet mean/std}. This keeps the prediction path consistent with the pretrained backbone assumptions while preserving enough spatial detail for fine-grained breed recognition.

The augmentation policy remains moderate:
\begin{itemize}[leftmargin=*, nosep]
    \item \textbf{ResNet-18}: random resized crop, horizontal flip, rotation, color jitter, and random erasing,
    \item \textbf{ViT-B/16}: milder crop, horizontal flip, color jitter, and random erasing.
\end{itemize}

This design aims to improve robustness to pose, illumination, and framing changes without destroying subtle breed cues.

\subsubsection{Model Building, Training, Evaluation, and Comparison}
The \textbf{ResNet-18} baseline uses full fine-tuning for \textbf{12 epochs}. The model contains \textbf{11,238,072} parameters and reaches a final test accuracy of \textbf{72.73\%}, macro F1 of \textbf{0.7193}, weighted F1 of \textbf{0.7283}, and ECE of \textbf{0.0394}. The total recorded training time is approximately \textbf{166.10 seconds}.

The \textbf{ViT-B/16} model uses a two-stage strategy: \textbf{3 epochs} of head-only training followed by \textbf{8 epochs} of full fine-tuning. The model contains \textbf{85,890,936} parameters and reaches a final test accuracy of \textbf{93.78\%}, macro F1 of \textbf{0.9343}, weighted F1 of \textbf{0.9378}, and ECE of \textbf{0.0161}. The total recorded training time is approximately \textbf{318.85 seconds}.

\subsubsection{Experimental Results, Figures, Analysis, and Discussion}
The final comparison shows a large performance gap in favor of \textbf{ViT-B/16}. On Stanford Dogs, the Transformer model performs much better than the smaller CNN baseline in both predictive quality and calibration quality. This is expected because Stanford Dogs is a fine-grained benchmark where small inter-class differences benefit from stronger representation capacity.

At the same time, \textbf{ResNet-18} remains meaningful as a lighter and faster baseline. Even though it is substantially weaker than ViT-B/16 on this dataset, it still provides a useful CNN reference point for the assignment-level CNN-versus-ViT comparison.

\subsubsection{Other Extension Reports}
The image track now includes the following completed extensions:

Together, these extensions make the image track more complete and more defensible in the final report, because they go beyond raw accuracy and provide interpretability, reliability, and experimental-setup analysis.

\subsection{Multimodal Track --- UPMC-Food101 Subset, CLIP ViT-B/16, and CLIP RN50}

\subsubsection{Problem and Dataset Exploration}
The multimodal task uses paired image-text inputs and compares \textbf{zero-shot} and \textbf{few-shot} multimodal classification. The report uses a 10-class subset of UPMC-Food101 and treats CLIP ViT-B/16 as the main backbone, with CLIP RN50 as the extension backbone. The task is well aligned with the assignment because each sample contains a true image-text pair rather than an artificially matched pair.

\subsubsection{Dataset, DataLoader, and Augmentation Setup}
The report page documents train/validation/test statistics and class-wise few-shot sampling. The custom multimodal dataset returns \texttt{(image, text, label)} tuples, supports augmentation and no-augmentation settings, and keeps the image and text branches aligned through the same label space. The 10 selected classes are: \textit{donuts, french\_fries, hamburger, hot\_dog, ice\_cream, pho, pizza, steak, sushi, tacos}.

\subsubsection{Model Building and Method}
The core backbone is CLIP, which provides both an image encoder and a text encoder in a shared embedding space. The multimodal report compares:
\begin{itemize}[leftmargin=*, nosep]
    \item zero-shot classification with prompt matching,
    \item few-shot adaptation with a \textbf{Linear classifier},
    \item few-shot adaptation with a \textbf{Prototype-based classifier},
    \item augmentation vs no-augmentation across ViT-B/16 and RN50.
\end{itemize}

\subsubsection{Experimental Results, Figures, Analysis, and Discussion}
The main ViT-B/16 backbone already achieves a strong zero-shot result and improves further with few-shot adaptation. The Prototype head is the most stable setting overall. RN50 is still competitive, but it is less consistent than ViT-B/16 and reacts more strongly to the chosen head and augmentation setting.
