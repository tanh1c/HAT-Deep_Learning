1. Problem and dataset exploration (EDA)

The image task is a multi-class classification problem comparing a CNN baseline and a Vision Transformer.

Problem statement

CNN vs ViT on CIFAR-10

The goal is to classify each image into one of ten semantic categories and compare two major model families under the same dataset and evaluation protocol.

  • CNN model: ResNet-18
  • Transformer model: ViT-B/16
  • Both initialized from ImageNet-pretrained weights

Dataset summary

Why CIFAR-10 fits this assignment

  • 10 classes
  • 50,000 training images
  • 10,000 test images
  • Original size: 32 x 32

CIFAR-10 is balanced, standard, and strong enough to reveal meaningful differences between CNN and Transformer representations.

Class labels

CIFAR-10 categories used in the image task

airplane automobile bird cat deer dog frog horse ship truck

2. Dataset, DataLoader, and augmentation setup

Both notebooks use the same CIFAR-10 source and a consistent preprocessing strategy for fair comparison.

Shared pipeline

Data loading and preprocessing

  • torchvision.datasets.CIFAR10
  • Resize to 224 x 224
  • Batch size: 64
  • num_workers: 4
  • pin_memory: True
  • persistent_workers: True

Both models are ImageNet-pretrained, so CIFAR-10 images are resized before inference and training.

Normalization and augmentation

Lightweight augmentation for both models

  • Normalize with mean = (0.4914, 0.4822, 0.4465)
  • Normalize with std = (0.2470, 0.2435, 0.2616)
  • RandomHorizontalFlip for training
  • No augmentation on test split

The augmentation policy is intentionally simple to keep the CNN vs ViT comparison focused on architecture and fine-tuning strategy.

3. Model building, training, evaluation, and comparison

The image section compares a lighter CNN baseline with a larger Transformer model.

CNN model

ResNet-18

  • Backbone: ResNet-18 pretrained on ImageNet
  • Final head replaced for 10 classes
  • Full fine-tuning for 30 epochs
  • Optimizer: AdamW, LR: 3e-4, weight decay: 1e-4
  • Warmup + cosine schedule
  • Total params: 11.18M

Transformer model

ViT-B/16

  • Backbone: ViT-B/16 pretrained on ImageNet
  • Final head replaced for 10 classes
  • 2-phase training: freeze 3 epochs, then full fine-tune 15 epochs
  • Optimizer: AdamW, phase-2 LR: 3e-5
  • Cosine schedule
  • Total params: 85.81M

4. Experimental results, figures, analysis, and discussion

The ViT model achieves the best final accuracy and the best confidence calibration on the CIFAR-10 test set.

Main takeaways

Accuracy and efficiency trade-off

  • ViT-B/16 achieves the strongest final accuracy and lower ECE.
  • ResNet-18 is much smaller and cheaper to train.
  • Both models are strong enough to make the architecture comparison meaningful.

Discussion

What the comparison shows

  • Residual errors are concentrated more in visually similar classes.
  • The ViT model produces more trustworthy confidence estimates.
  • The CNN model remains valuable as a compact, efficient baseline.
